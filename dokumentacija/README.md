# Dokumentacija projekta SpendWise

Projekt SpendWise je mobilna aplikacija za upravljanje osebnih financ, razvita pri predmetu Razvoj vseprisotnih informacijskih rešitev (RVIR), študijsko leto 2026/2027.

## Vsebina dokumentacije

V tej mapi bodo shranjeni:

- Podrobnejši opis projekta in glavnih funkcionalnosti.
- Diagram primerov uporabe.
- Mockupi ključnih zaslonov in načrt navigacije.
- Začetni podatkovni model.
- Arhitektura aplikacije in predvidene tehnologije.
- Načrt razvoja in razdelitev odgovornosti.
